# CRT CITY — Windows 실행판

쿼터뷰 턴제 도시 경영 게임 **CRT CITY**의 Windows 실행 파일 배포 저장소입니다. (소스 코드는 여기 없습니다.)

## 설치

1. **[최신 버전 내려받기 (CRT_CITY_win64.zip)](https://github.com/Celzook/crt-city-releases/releases/latest/download/CRT_CITY_win64.zip)**
2. 압축을 풀고 `CRT CITY` 폴더를 바탕화면·문서 등에 둡니다 (`C:\Program Files` 안은 피하세요).
3. `CRT CITY.exe` 실행. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.

## 업데이트

게임을 켤 때마다 새 버전을 확인하고, 있으면 알림 창이 뜹니다. **예**를 누르면 자동으로 받아서 바꾼 뒤 다시 실행됩니다.

## 세이브

`%LOCALAPPDATA%\CRT_CITY\saves` 에 저장되므로 업데이트하거나 폴더를 새로 받아도 유지됩니다.
